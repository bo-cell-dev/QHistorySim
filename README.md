# QHistorySim

A desktop browser history simulator built with **C++17** and **Qt 6 (Widgets)**. The project visually demonstrates how browser navigation (`Back` and `Forward`) works under the hood using a dual-stack data structure (`QStack`).

<img width="1917" height="987" alt="image" src="https://github.com/user-attachments/assets/0c43fdbe-8a6c-434b-907a-f40aff7b382f" />

## Features
* **Dual-Stack Visualization:** Real-time display of `Back Stack` and `Forward Stack` states.
* **Navigation Controls:** Standard `Back`, `Forward`, and `Clear History` actions with automatic button state handling.
* **Custom URL Input & Presets:** Visit custom addresses via the input bar.
* **Custom UI:** Responsive layout styled with Qt Style Sheets (QSS) featuring a dark pink-and-blue gradient theme.

## Tech Stack
* **Language:** C++17
* **Framework:** Qt 6 (Core, Widgets)
* **Build System:** CMake
